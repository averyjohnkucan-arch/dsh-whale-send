# Whale Send for DeepSeek Harness RC4

In **Plugins → Add plugin**, paste `https://github.com/averyjohnkucan-arch/dsh-whale-send` and enable **Whale Send**. Send the first message in a new web chat with the Send button or Enter. The conversation controls fade away over the first 500 milliseconds. The welcome heading fades with the controls. The sidebar stays visible and interactive throughout. Your submitted message floats from the composer to the center of the screen over the first 500 milliseconds. The whale is already moving behind it at twice its normal opacity. The last 500 milliseconds of the 5.7-second animation reveal the full, live chat. The message is submitted immediately. Click or press a key in the conversation to reveal the conversation sooner.

Requires DeepSeek Harness 0.2.2-rc.4 and its official brand plugin. The effect respects the browser’s reduced-motion preference and uses the whale artwork shipped with the host. Subsequent messages use the standard chat UI.
