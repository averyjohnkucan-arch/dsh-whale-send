# Whale Send for DeepSeek Harness RC4

In **Plugins → Add plugin**, paste `https://github.com/averyjohnkucan-arch/dsh-whale-send` and enable **Whale Send**. Send the first message in a new web chat with the Send button or Enter. The home whale plays at twice its normal opacity for 5.7 seconds, then fades into the conversation over 250 milliseconds. The message is submitted immediately. Click or press a key to reveal the conversation sooner.

Requires DeepSeek Harness 0.2.2-rc.4 and its official brand plugin. The effect respects the browser’s reduced-motion preference and uses the whale artwork shipped with the host. Subsequent messages use the standard chat UI.
